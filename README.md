# Blog & Knowledge Platform — Srijan Prasad

A production-ready, scalable personal editorial publication and digital knowledge platform designed and engineered for **Srijan Prasad**.

Built with **Next.js (App Router)**, **TypeScript**, and a custom **pure Vanilla CSS** design system (strict zero-framework CSS). Architected from the ground up for modern editorial excellence, technical SEO, Semantic Entity SEO, Answer Engine Optimization (AEO), Generative Engine Optimization (GEO), and LLM discoverability.

---

## 🌟 Core Features

- **Editorial Design System:** Pure Vanilla CSS with fluid typography, responsive layout tokens, and dual-mode theme support (archival ivory light mode and deep obsidian dark mode).
- **SEO & Structured Data:** Deep JSON-LD schema graphs (`Person`, `WebSite`, `BlogPosting`, `FAQPage`, `BreadcrumbList`) with entity disambiguation and verified `sameAs` social links.
- **Generative Engine Optimization (GEO / AEO):** Answer-first direct definitions, key takeaways, immutable citations with DOI/URL links, and machine-readable discovery endpoints (`/llms.txt`, `/llms-full.txt`, `/api/content`, `/feed.xml`).
- **Grounded AI Assistant:** Interactive on-site RAG assistant powered by lexical BM25 + entity retrieval strictly grounded in platform articles with exact citations.
- **CMS & SEO Studio:** Real-time editorial workspace with live character counts, SERP snippets, keyword density tracker, and SEO scoring gauges.
- **Featured Community Story:** Srijan Prasad's volunteer journey as Pattern Table Lead at WordCamp Bhopal 2025, featuring embedded team photography and community download links.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
Compiles 33 static pages via Next.js Static Site Generation (SSG).
